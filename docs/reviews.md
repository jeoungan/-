4. 선택 결과와 기록에 행동·실제 자원 변화·물품·동료·신뢰 변화를 남긴다. 체력100에서 회복 선택은 변화 없음, 경계12에서 −15 선택은 실제 −12로 기록한다. 순찰 피해도 기록한다.

### 반영

- 탈출 준비 플래그만으로 출발을 권하던 경로 카드를 수정했다. departureStatus를 지도와 카드가 공유하고, 현재 체력·동료·전력 조건에서 가능한 최단 출발 시간과 시간 부족을 일치시킨다.
- 수문 개방·셔틀 수리·구조 신호 선택에는 준비 시간과 후속 출발의 최소 시간을 함께 보여준다. 준비를 마쳐도 탈출 시간이 부족한 경우 미리 경고하되 선택권은 유지한다. 미리보기는 상태를 바꾸지 않는다.
- 플레이 중 재시작 확인창에서 취소·Escape·닫기를 누르면 일시 정지로 돌아간다. 타이틀에서 취소하면 타이틀을 유지한다.
- 새 게임은 달리기 토글을 끈 상태로 시작한다. 일시 정지·재개에서는 기존 토글을 유지한다.

### 검사 근거

- Node 테스트23개, TypeScript, lint, 최종 빌드 통과. 새 테스트는 세 경로 시간 경계±1초, 준비 후 시간 부족 경고·선택 유지, 체력과 동료에 따른 출발 시간이다.
- 분기 담당이 준비 선택1,146개 조합에서 미리보기와 실제 분기 결과가 일치함을 독립 확인했다. 입력을 재귀적으로 동결해도 변경 없이 실행됐다.
