### 원작에서 실제 확인한 것

https://last-shuttle.jpcgpt.chatgpt.site/ 에서 중앙 광장 → 본관 → 실습실 → 학생증·비상 퓨즈 획득까지 실제 진행. 필수 목표는 이후 전기실 복구와 정류장. 23:17 시작, 23:40 셔틀, 체력3, 소음0~4, 가방4칸, 클릭/지도 목적지 이동, WASD·Shift·E. 자유 이동 시간은 고정이고 장소·조사 선택에 시간 비용. 모달에서 적과 플레이어 정지. 실제 물림과 체력3→2, 점수 감소 확인. 모바일은 조이스틱·조사·달리기를 별도 배치.

원작 결말은 확인하지 못했다. 원작의 엔딩이 하나라거나 분기가 없다고 주장하지 않는다. 실습실 NPC 옆에서 조사 비활성 상태를 보았지만 선행 조건/버그 여부는 불명확하다.

### 새 게임에서 구현한 확장

- 7개 조사 지점, 통로 충돌과 길찾기, 직접 이동·달리기·자동 도착 조사, 두 순찰 감지 영역.
- 셔틀/수문/옥상 탈출에 각각 아이템·전력·동료·시간을 대체하는 경로.
- 서윤/민재/도하 3인과 신뢰, 광장 대화. 수문 피해·송신 전력·수리에 실제 영향.
- 원본 봉쇄 지시, 환자 기록, 제어기 변경의 독창적 이야기. 증거 2개 공개 방송으로 특별 결말.
- 7개 결말, 구조 승객 변주, 경로·동료·증거 결과. 기록과 기기별 이어하기·엔딩 도감.
- 선택의 비용/잠김 이유를 미리 표시하고, 모달을 닫아 보류 가능.

### 독립 리뷰에서 찾아 반영한 문제

1. 저장 검증이 상속 키와 잘못된 lastEvent, 중복 아이템, 소수 전력, 범위 밖 신뢰, 무한 쿨다운을 받음 → own-property, 정확한 타입·범위·고유성 검사, 고유 증거 계산 추가.
2. 체력≤8·전력0 옥상 수동 송신이 막힘 → 7분·체력 소모0 대체.
3. 모바일 HUD가 지도 아래 멀리 위치 → 탐험 상단에 시간·체력·경계·전력 sticky 요약 추가.
4. UI 탭 방향키가 이동 키로도 처리될 가능성 → defaultPrevented와 tab/slider 등 인터랙티브 포커스 제외.
5. 키보드가 자동 이동을 취소해도 목적지 문구 남음 → 문구 함께 제거.
6. 선택 결과 제목이 다음 사건으로 앞서 바뀜 → 결과 표시 중 '선택이 남긴 변화'로 고정.
7. 작은 상단·기록 버튼 → 터치 영역 확장. 지도 핀과 동일 행동의 목적지 목록은 44px 높이.
8. 타이틀·모달에 불필요한 130ms React 상태 갱신 → 탐험 중에만 갱신.

- 순찰 접근을 비시각적 짧은 텍스트로도 알리기. 접근성 친화 난이도/턴 기반 탐험 옵션은 사용자 의도에 맞춰 검토.
- 지도 핀에 방문 여부 외에 '추가 조사 남음/증거/출발 준비'를 구체적으로 구분.
- 기록에서 실제 자원 변화와 선택한 행동을 결과 문장 옆에 함께 보이기.
