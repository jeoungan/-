4. 선택 결과와 기록에 행동·실제 자원 변화·물품·동료·신뢰 변화를 남긴다. 체력100에서 회복 선택은 변화 없음, 경계12에서 −15 선택은 실제 −12로 기록한다. 순찰 피해도 기록한다.
